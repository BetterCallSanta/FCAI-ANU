Chapter 1 — Vectors

Scalar & Vector، Components، جمع وطرح المتجهات

1) Scalar vs Vector

Scalar

مقدار فقط: mass, time, distance, speed, energy.

Vector

مقدار واتجاه: displacement, velocity, acceleration, force.

2) Components (لو θ من محور +x)

Aₓ = A cos θ   |   Aᵧ = A sin θ
A = √(Aₓ² + Aᵧ²)   |   θ = tan⁻¹(Aᵧ/Aₓ)
إشارات المركبات تعتمد على الربع: (+,+) الربع الأول، (−,+) الثاني، (−,−) الثالث، (+,−) الرابع. راجع الربع بعد استخدام tan⁻¹.

3) Unit-vector notation

A⃗ = Aₓ î + Aᵧ ĵ (+ A_z k̂)

4) Addition / Subtraction

Rₓ = Aₓ + Bₓ   |   Rᵧ = Aᵧ + Bᵧ
For A − B: Rₓ = Aₓ − Bₓ   |   Rᵧ = Aᵧ − Bᵧ
R⃗ = Rₓ î + Rᵧ ĵ   |   R = √(Rₓ² + Rᵧ²)

5) Dot Product (لو ضمن المحتوى المطلوب)

A⃗ · B⃗ = AB cos θ = AₓBₓ + AᵧBᵧ (+ A_zB_z)
الناتج scalar. مفيد لحساب الزاوية أو projection لو السؤال طلبه.

6) Cross Product (لو مطلوب 3D)

|A⃗ × B⃗| = AB sin θ
في 2D: قيمة z = AₓBᵧ − AᵧBₓ، واتجاهه يحدد بقاعدة اليد اليمنى.

Exercise pattern

  1. ارسم المحورين واتجاه المتجه.
  2. حدد الزاوية بالنسبة لأي محور.
  3. حلّل إلى x و y مع الإشارات.
  4. اجمع المركبات منفصلة.
  5. احسب magnitude ثم angle وحدد الربع.

Chapter 2 — Motion in One Dimension

Displacement, velocity, acceleration، constant acceleration & free fall

1) Displacement, Average Velocity & Speed

Δx = x_f − x_i   |   Δt = t_f − t_i
v_avg = Δx / Δt
Average speed = Total distance / Total time
الإزاحة والسرعة المتجهة لها اتجاه وإشارة. المسافة والـ average speed موجبتان أو صفر. المسافة مش لازم تساوي مقدار الإزاحة لو الجسم غيّر اتجاهه.

2) Instantaneous velocity & acceleration (مشتقات)

vₓ = dx/dt   |   aₓ = dvₓ/dt = d²x/dt²
If x(t) is given: differentiate once → velocity; twice → acceleration.
If v(t) is given: differentiate → acceleration.

مشتقات سريعة

d(C)/dt = 0   |   d(tⁿ)/dt = ntⁿ⁻¹
d(At + Bt² + Ct³)/dt = A + 2Bt + 3Ct²

3) Average Acceleration

a_avg = (v_f − v_i) / (t_f − t_i) = Δv/Δt

4) Constant-Acceleration Kinematics (احفظ الأربع)

v_f = v_i + at
لا يوجد displacement
Δx = (v_i + v_f)t / 2
لا يوجد acceleration
Δx = v_i t + ½at²
لا يوجد final velocity
v_f² = v_i² + 2aΔx
لا يوجد time
x_f = x_i + Δx

5) Free Fall

g ≈ 9.8 m/s² downward
If +y upward: a_y = −g
v_yf = v_yi − gt   |   Δy = v_yi t − ½gt²
v_yf² = v_yi² − 2gΔy
Δy = (v_yi + v_yf)t / 2
عند أعلى نقطة في رمية رأسية: v_y = 0 فقط؛ العجلة ما زالت −g. اختار محور موجب واستخدم الإشارات طوال المسألة.

Derived relations for vertical throw

Time to top: t_up = v₀/g (لو initial upward)
Maximum rise: h = v₀²/(2g)
Return to same level: T = 2v₀/g, v_return = −v₀

اختيار القانون بسرعة

المطلوباستخدم
v و t و av_f = v_i + at
Δx و v_i و t و aΔx = v_it + ½at²
Δx و السرعتين و tΔx = ½(v_i+v_f)t
بدون tv_f² = v_i² + 2aΔx

Chapter 3 — Motion in Two Dimensions

Vector motion، projectile motion، circular motion

1) Vector position, velocity & acceleration

r⃗ = x î + y ĵ
v⃗ = dr⃗/dt = vₓ î + vᵧ ĵ
a⃗ = dv⃗/dt = aₓ î + aᵧ ĵ
v = √(vₓ² + vᵧ²)   |   θ = tan⁻¹(vᵧ/vₓ)

2) Constant acceleration in 2D — كل محور لوحده

X-axis

vₓf = vₓi + aₓt
Δx = vₓi t + ½aₓt²
vₓf² = vₓi² + 2aₓΔx

Y-axis

vᵧf = vᵧi + aᵧt
Δy = vᵧi t + ½aᵧt²
vᵧf² = vᵧi² + 2aᵧΔy
rf = ri + vit + ½at²
vf = vi + at
محور x ومحور y مستقلان في الحساب، لكن الزمن t واحد في الاتنين. حل معادلة المحور اللي تقدر تطلع منها الزمن، وبعدها استخدم الزمن في المحور الآخر.

3) Projectile assumptions

  • Air resistance neglected.
  • aₓ = 0, so vₓ is constant.
  • aᵧ = −g (لو +y لأعلى).
  • Initial velocity at angle θ from horizontal.

4) Resolve initial velocity

vₓi = v₀ cos θ   |   vᵧi = v₀ sin θ

Projectile equations (general — حتى لو launch/landing heights مختلفة)

x = x₀ + (v₀ cos θ)t
y = y₀ + (v₀ sin θ)t − ½gt²
vₓ = v₀ cos θ   |   vᵧ = v₀ sin θ − gt
Speed: v = √(vₓ² + vᵧ²)

5) Special case: same launch and landing height

Time of flight

T = 2v₀sinθ / g

Maximum height

H = v₀²sin²θ / (2g)

Range

R = v₀²sin(2θ) / g

Max range

θ = 45° ; R_max = v₀²/g

6) Trajectory equation (eliminate time)

y − y₀ = (tan θ)(x − x₀) − g(x − x₀)²/[2v₀²cos²θ]
بتدي شكل المسار parabola. استخدمها لما السؤال يطلب y بدلالة x أو معادلة المسار.
قوانين range وflight time بالشكل المختصر تفترض إن نقطة الهبوط على نفس ارتفاع الإطلاق. لو من سطح مبنى/حافة، استخدم معادلة y(t) وحل quadratic للزمن.

مشتقات مفيدة للـ projectile

x(t) = x₀ + v₀cosθ·t ⟹ dx/dt = v₀cosθ
y(t) = y₀ + v₀sinθ·t − ½gt² ⟹ vᵧ = v₀sinθ − gt
d²y/dt² = −g

خطة حل مسألة المقذوفات

  1. ارسم trajectory والمحاور، وحدد y₀ وy_final.
  2. حلل v₀ لمركبتين.
  3. اكتب x-equation وy-equation.
  4. استخرج الزمن من المحور الذي فيه المعطيات كاملة.
  5. عوّض الزمن في المحور الآخر.
  6. لو مطلوب final velocity: احسب vₓ وvᵧ ثم magnitude & direction.

Circular Motion — الحركة الدائرية

1) Angular & period relationships

Circumference = 2πr
T = time for one revolution   |   f = 1/T
v = 2πr/T = 2πrf
ω = 2π/T = 2πf   |   v = ωr
لو الدوران بوحدة rev/min: حوّل إلى rev/s بقسمة على 60، وبعدها ω = 2πf بوحدة rad/s.

2) Centripetal / Radial acceleration

a_c = v²/r = ω²r = 4π²r/T²
a⃗_r points toward center (inward)

3) Tangential acceleration

a_t = d|v|/dt = dv/dt
a⃗ = a⃗_r + a⃗_t
a_total = √(a_r² + a_t²) (perpendicular components)
tan φ = |a_r|/|a_t| (check angle reference)

4) Useful derivations

v = 2πr/T ⟹ a_c = v²/r = 4π²r/T²
ω = 2πf ⟹ a_c = ω²r

Exercises typically ask

  • Given r and rpm, find v and centripetal acceleration.
  • Given T and r, find a_c.
  • Curved road: combine radial acceleration with tangential acceleration.
  • Given total acceleration and one component, solve for the other using Pythagoras.

Nₐ = 6.02 × 10²³ atoms/mol
Mass of one atom = Molar mass / Nₐ
Number of atoms: N = (m / molar mass) × Nₐ

5) Dimensional Analysis

طريقة حل مسائل التحليل البُعدي

  2. لو بتختبر قانون: لازم أبعاد الطرفين تتساوى.
  3. لو بتستنتج قانون تناسب، افترض القوى المجهولة ثم ساوي الأسس.

Exercise Toolkit — إزاي تختار القانون وتحل

خطوات عامة لأي مسألة من الشيتات

1 · Write the givens

اكتب كل قيمة مع الوحدة: xᵢ, x_f, vᵢ, v_f, a, t, θ, r.

2 · Draw

رسم صغير، محور موجب، اتجاه الحركة، الزاوية، وأي ارتفاع/نقطة بداية ونهاية.

3 · Convert units

وحّد SI: m, s, kg. السرعات غالبًا m/s والعجلة m/s².

4 · Choose relation

اختار القانون اللي فيه المجهول ويحتوي المعطيات المتاحة، ويفضل أقل مجهولات إضافية.

5 · Solve symbolically

رتّب القانون للمجهول قبل التعويض لتقلل أخطاء الحساب.

6 · Check

راجع الإشارة، الوحدة، والنتيجة منطقية؟ اتجاه الحركة/الربع صحيح؟
